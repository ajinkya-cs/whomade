# whomade

Who made this image? `whomade` verifies C2PA Content Credentials against the official C2PA trust list and reads the metadata AI generators leave behind. It runs locally: no uploads, no API keys.

```console
$ npx whomade amsterdam.png
amsterdam.png
  AI-generated by ChatGPT (gpt-image): verified C2PA signature
  verified c2pa  Signed by OpenAI OpCo, LLC, chaining to Trufo C2PA Root CA (2025, ECC P384) on the C2PA trust list. Declares trainedAlgorithmicMedia. Declares an invisible watermark.
```

## Use

**CLI**

```sh
npx whomade photo.jpg https://example.com/image.png
npx whomade photo.jpg --json     # one JSON report per line
```

**MCP server** — lets an assistant answer "who made this image?"

```sh
claude mcp add whomade -- npx -y whomade mcp
```

For Claude Desktop, Cursor and other clients:

```json
{ "mcpServers": { "whomade": { "command": "npx", "args": ["-y", "whomade", "mcp"] } } }
```

The server exposes one read-only tool, `who_made`, which takes a file path or URL.

**Library**

```ts
import { describe, whomade } from 'whomade';

const report = await whomade(await readFile('photo.jpg')); // Uint8Array or ArrayBuffer
report.ai;          // true | false | null
describe(report);   // "AI-generated by ChatGPT (gpt-image): verified C2PA signature"
```

```ts
interface Report {
  ai: boolean | null;                          // null: no evidence either way
  origin?: 'generated' | 'edited' | 'captured';
  confidence: 'verified' | 'signed' | 'claimed' | 'none';
  generator?: string;
  evidence: { source: 'c2pa' | 'xmp' | 'exif' | 'png'; confidence; origin?; generator?; signer?; detail: string }[];
}
```

## What it checks

| Source | Formats | Examples |
| --- | --- | --- |
| C2PA Content Credentials | JPEG, PNG, HEIF, AVIF | ChatGPT, Adobe Firefly, Google, Samsung and Pixel cameras |
| IPTC digital source type (XMP) | JPEG, PNG, WebP | Google, Meta |
| Generator metadata | PNG | AUTOMATIC1111, Forge, ComfyUI, InvokeAI, NovelAI |
| EXIF Software | JPEG, PNG, WebP | tools that sign their name |

Each piece of evidence gets one of three confidence levels:

| Confidence | Meaning |
| --- | --- |
| `verified` | Valid C2PA signature from a certificate that chains to the [C2PA trust list](https://github.com/c2pa-org/conformance-public). |
| `signed` | Valid C2PA signature, but the certificate is not on the trust list. Anyone can make one. |
| `claimed` | Unsigned metadata, or a C2PA manifest that fails validation. Easy to fake or strip. |

## Limits

- Most sites, messaging apps and screenshots strip metadata. **`ai: null` means no evidence, not "made by a human".**
- Invisible watermarks such as Google's SynthID (also used by OpenAI) are not detected; only their vendors can check them. Use [synthid.com](https://synthid.com) or [openai.com/verify](https://openai.com/verify).
- Detection is evidence-based, not a pixel classifier, so it never guesses.
